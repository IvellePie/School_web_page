# Página web Colegio/School web page
## Español
Una página que permite tanto a estudiantes como padres ver las notas escolares. Tambien, permite a los profesores visualizar y cambiar las notas en tiempo real. Esta enfocado en las personas daltonicas para facilitar su acceso y comprension de la interfaz
### Contexto
Este proyecto fue hecho para participar en una competencia intercolegial. El proyecto se ganó el primer lugar en programacion estructurada.
### Funcionalidades
* **Padres y estudiantes:** Ingresar a ver las notas escolares de ellos o de sus hijos.
* **Profesores:** Editar las notas de sus estudiantes y guardarlas
### Tecnologias
* Python
* Html/CSS
## English
A web page that allows students and parents to see the school grades. It also alows teachers to view and change the grades in real time. The proyect is focused on color blind people to make their access and understanding of interface easier.
### Context
This proyect was made to take part in an interscholastic competition. The proyect won the fisrt place in structured programming.
### Functions
* **Parents and students:** Log in to see their grades.
* **Teachers:** Edit the grades of their students and to save them.
#### Technologies
* Python
* Html/CSS
